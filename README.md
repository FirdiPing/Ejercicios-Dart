<h2>Descripción\</h2>

<p>
Repositorio dedicado a la realización y recopilación de ejercicios prácticos de \<strong>Dart\</strong>, correspondientes a la asignatura de \<strong>Programación Multimedia y de Dispositivos Móviles\</strong>.
\</p>

<p>
Los ejercicios están organizados por relaciones y numerados individualmente para facilitar su consulta, ejecución y seguimiento.
\</p>

<p>
El objetivo es aprender progresivamente el lenguaje Dart, desde sus conceptos fundamentales hasta el desarrollo de funciones, estructuras de datos, algoritmos y programación recursiva.
\</p>

<h2>Contenido del repositorio\</h2>

<h3>🟣 Relación 1 – Ejercicios iniciales de Dart\</h3>

\<p>
Introducción al lenguaje Dart y a sus principales características, trabajando con variables, operadores, estructuras de control, colecciones y diferentes algoritmos.
\</p>

| Ejercicio | Contenido                                          |
| :-------: | -------------------------------------------------- |
|     01    | Hola mundo, variables y comentarios                |
|     02    | Tipos de datos y operadores                        |
|     03    | Constantes: `const` y `final`                      |
|     04    | Variables nullable                                 |
|     05    | Clasificación de triángulos                        |
|     06    | Calculadora básica                                 |
|     07    | Ecuaciones de segundo grado                        |
|     08    | Tabla de multiplicar con entrada por consola       |
|     09    | Tablas de multiplicar del 1 al 10                  |
|     10    | Suma de números naturales                          |
|     11    | Factorial de un número                             |
|     12    | Máximo común divisor (MCD)                         |
|     13    | Cociente y resto mediante el algoritmo de Euclides |
|     14    | Simulación del lanzamiento de un dado              |
|     15    | Simulación de múltiples lanzamientos y frecuencias |
|     16    | Listas, Map y recorrido con `forEach`              |
|     17    | Enumeraciones (`enum`)                             |
|     18    | Gestión de excepciones con `try-catch-finally`     |
|     19    | Recorrido de Map: claves y valores                 |
|     20    | Estadísticas de temperaturas                       |

\<h4>Conceptos trabajados\</h4>

- Variables y tipos de datos.
- Operadores y conversiones.
- Constantes y variables nullable.
- Condicionales y estructuras de repetición.
- Entrada de datos por consola.
- Funciones matemáticas.
- Librerías, listas, mapas y enumeraciones.
- Excepciones y gestión de errores.

\<h3>🟣 Relación 2 – Ejercicios con funciones\</h3>

\<p>
Profundización en la creación, utilización y reutilización de funciones, trabajando con parámetros, valores de retorno, algoritmos matemáticos, recursividad y librerías propias.
\</p>

| Ejercicio | Contenido                                        |
| :-------: | ------------------------------------------------ |
|     01    | Función sin parámetros ni retorno: fecha y hora  |
|     02    | Funciones con parámetros                         |
|     03    | Parámetros opcionales con valores por defecto    |
|     04    | Parámetros nullable                              |
|     05    | Funciones con devolución de valores (`return`)   |
|     06    | Suma de los n primeros números naturales         |
|     07    | Factorial mediante funciones                     |
|     08    | MCD mediante el algoritmo de Euclides            |
|     09    | Cálculo del cociente y resto                     |
|     10    | Conversión de números a binario y otras bases    |
|     11    | Estadísticas de temperaturas mediante listas     |
|     12    | Estadísticas de temperaturas mediante Map        |
|     13    | Comprobación de números primos                   |
|     14    | Suma de naturales mediante recursividad          |
|     15    | Factorial mediante recursividad                  |
|     16    | MCD mediante recursividad                        |
|     17    | Cociente y resto mediante recursividad           |
|     18    | Generación de la serie de Fibonacci              |
|     19    | Generación de listas de números primos           |
|     20    | Creación e importación de librerías de funciones |

\<h4>Conceptos trabajados\</h4>

- Declaración y llamada de funciones.
- Parámetros posicionales y opcionales.
- Valores por defecto y tipos nullable.
- Funciones con y sin retorno.
- Algoritmos matemáticos.
- Recursividad.
- Listas y mapas.
- Reutilización de código.
- Creación e importación de librerías propias.
- Principio de responsabilidad única (SRP).
